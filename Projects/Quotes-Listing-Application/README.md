# Quotes App

A simple React application that fetches and displays inspirational quotes using the FreeAPI Quotes API.

## Features

- Fetch quotes from API
- Display author and quote content
- Loading state
- Responsive modern UI

## Tech Stack

- React
- Vite
- CSS

## API Used

https://api.freeapi.app/api/v1/public/quotes
