# Resume Page

A simple resume webpage created as part of the Chai Code Web Dev Cohort 2026 assignments.

## 📌 Objective

Build a clean and well-structured resume webpage using semantic HTML.  
Use appropriate tags such as `header`, `main`, and `footer`, add section-wise comments for clarity, and ensure proper usage of headings, paragraphs, lists, tables, and sections while keeping the layout readable and close to the reference.

## Tech Stack

- HTML

## ⚙️ Setup Instructions

Follow these steps to run the project locally:

1. Clone the repository

   ```bash
   git clone https://github.com/dnano-more/chai-code-webdev-cohort-2026.git
   ```

2. Navigate to the assignment folder

    ```bash
    cd chai-code-webdev-cohort-2026/Assignments/01_Resume_Page
    ```

3. Open index.html in your browser
(Optional: use Live Server extension in VS Code)

## ▶️ Usage

- View the resume layout in the browser
- Edit index.html to update personal details
- Practice semantic HTML and proper document structure
