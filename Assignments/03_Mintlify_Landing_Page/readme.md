# Mintlify Landing Page

A Mintlify landing page created as part of the Chai Code Web Dev Cohort 2026 assignments.

## 📌 Objective

Created a clone of Mintlify landing page using HTML and raw CSS. Lots of things learned while bilding this project like flexbox, positioning, pseudo elements etc. Tried to match the design as close as possible.

## Tech Stack

- `HTML`
- `CSS`

## 🎨 Fonts And Colors

- Font: InterVariable

- Colors:
    - Background: `#08090a`
    - Text: `lab(100% 0 0)`

## ⚙️ Setup Instructions

Follow these steps to run the project locally:

1. Clone the repository

   ```bash
   git clone https://github.com/dnano-more/chai-code-webdev-cohort-2026.git
   ```

2. Navigate to the assignment folder

    ```bash
    cd chai-code-webdev-cohort-2026/Assignments/03_Mintlify_Landing_Page
    ```

3. Open index.html in your browser
(Optional: use Live Server extension in VS Code)
